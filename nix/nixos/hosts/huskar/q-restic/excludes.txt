# huskar 的 restic 排除清单，由 Nix 部署；修改后需 rebuild。
#
# 匹配规则（已实测）:
#   $HOME/...        → 按仓库里存储的绝对路径精确匹配，如 $HOME/.cache
#   /...             → 锚定在**文件系统根**（不是 $HOME），如 /bin
#   不含 / 的模式    → 匹配任意层级下同名的文件或目录，如 node_modules
#   **               → restic 扩展通配，可跨目录层级
#
# **别写死 /home/<用户名>**：restic 会用 os.ExpandEnv 展开 exclude 文件里的环境变量，
# 所以写 $HOME 就能跨机器、跨用户名复用（`~` 不会被展开，别用；要字面 $ 就写 $$）。
# q-restic 侧还有一层保险：restic_env() 会给子进程 setdefault HOME。
#
# 不用 --one-file-system：/home 下没有嵌套挂载点，加了只会平白跳过东西。
